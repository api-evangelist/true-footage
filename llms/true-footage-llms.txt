## What an agent can and cannot do here

**There is no public API program.** True Footage runs real, production platform APIs, but
they are closed. As of 2026-08-05 an unauthenticated agent can do nothing programmatic with
True Footage beyond reading its marketing site.

- `https://api.truetracts.truefootage.tech` — HTTP 401 on every path, including
  `/openapi.json`, `/docs`, `/redoc`, `/swagger.json` and every `/.well-known/` path.
  Body: `{"detail":"authorization header is expected"}`. Only `/health` returns 200.
- `https://api.trueengine.truefootage.tech` — identical posture.
- No OpenAPI, AsyncAPI, GraphQL SDL, JSON Schema, or Postman collection is published anywhere.
- No MCP server, no A2A agent card, no `/.well-known/agent-card.json`, no `llms.txt`.
- No public GitHub organization; no packages on npm, PyPI, Maven Central, NuGet, pkg.go.dev,
  RubyGems, Packagist or crates.io.
- No status page. `truefootage.statuspage.io` resolves but redirects to Atlassian's product
  marketing page — it is not a True Footage status page.

## Authentication

Both product surfaces sit behind Auth0 custom identity domains that True Footage operates
under its own DNS. Their OpenID Connect discovery documents are the only machine-readable
contracts the company serves anonymously.

- TrueTracts: `https://auth.truetracts.truefootage.tech/.well-known/openid-configuration`
- TrueEngine: `https://auth.trueengine.truefootage.tech/.well-known/openid-configuration`

Both advertise `authorization_code`, `client_credentials`, `refresh_token`, device code and
token-exchange grants, PKCE with `S256`, and `private_key_jwt` client authentication. The
advertised `scopes_supported` are the fourteen standard OIDC identity scopes only — there is
no product-specific permission surface. Credentials are issued through a TrueTracts
subscription, not through a developer signup.

See `authentication/true-footage-authentication.yml` and `well-known/true-footage-well-known.yml`.

## Products

- **TrueTracts** — appraiser analysis console. Market definition, comparable selection, time
  and feature adjustments via generalized additive models, dynamic heat mapping for
  locationally similar properties, automatic 1004MC completion, PDF workfile export.

## Security posture

TLS 1.3 across all hosts. HSTS on the marketing site (max-age 31536000) but not on either
API host. SPF and DMARC published (`p=quarantine`); no DNSSEC and no CAA records on
`truefootage.tech`. No `/.well-known/security.txt`, no published vulnerability disclosure
policy, no bug bounty, and no trust center or named certifications.
